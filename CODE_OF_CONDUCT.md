# Code of conduct

Holt's project spaces should be useful, safe places to collaborate. Treat other people with
respect, critique ideas and evidence rather than individuals, and make room for different levels
of experience and background.

Harassment, threats, discriminatory language, sexualised attention, deliberate intimidation,
doxxing, and publishing another person's private information are not acceptable. Neither is
using an issue or review to pressure someone into revealing private repository data, credentials,
or security-report details.

This policy applies to project-controlled issues, pull requests, reviews and discussions. Project
maintainers may edit or remove contributions, close or lock threads, or restrict participation when
needed to protect the community. Enforcement is best effort and has no promised response time.

If it is safe to do so, flag the specific project content to a maintainer through a GitHub issue.
For abuse that should not be restated publicly, use GitHub's platform reporting and blocking tools.
The project does not currently advertise a dedicated private conduct-reporting inbox; do not put
sensitive personal information into a public report.
