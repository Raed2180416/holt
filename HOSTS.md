# Agent host coverage

holt integrates with AI coding agents three ways, strongest first: a **deterministic blocking hook**, an **MCP server**, or an **advisory rules file** (AGENTS.md). Plus a universal git floor (the worktree lock + pre-commit hook) that needs no host cooperation. This page tracks holt's own manifest — run `holt hosts` to see the live, current version against *your* machine (that command reads the manifest directly and cannot drift; this file is generated from the same manifest, see below).

The table and the cloud-caveat paragraph below are **generated** from `src/integrate/hosts.mjs` (the `HOSTS` array, `strengthLabel()`, and the `CLOUD_CAVEAT` export) by `npm run hosts:generate`. `npm run hosts:check` — wired into CI — fails the build if this file disagrees with what the generator produces from the current manifest, the same ratchet shape `npm run typecheck` uses elsewhere in this repo. That guarantee did not always exist: this file was hand-synced before, and it drifted from the manifest at least twice — Cursor's promotion to a docs-verified block hook went unreflected here for a while, and Roo/Kilo's split into two products (plus Goose's and Amazon Q's corrected classification) showed up as a single stale row. Hand-sync is the kind of chore that quietly stops happening; making drift structurally impossible is the actual fix. Everything between the `HOLT:HOSTS-TABLE` and `HOLT:CLOUD-CAVEAT` markers below is regenerated — do not hand-edit it, edit the manifest instead and run the generator.

## The cloud caveat

<!-- HOLT:CLOUD-CAVEAT:BEGIN — generated from the CLOUD_CAVEAT export in src/integrate/hosts.mjs. Do not hand-edit between these markers. -->
holt's worktree lock and git pre-commit hook are LOCAL guarantees — they do not apply to cloud/ephemeral agents (Google Jules, Replit Agent, Devin cloud sessions), which run on a remote sandbox with no local worktree. There, holt reaches the agent only through an advisory AGENTS.md. Stated plainly rather than glossed.

## Reading this table

- **BLOCKING** — holt writes a hook the host enforces; a destructive command is refused before it runs, no model cooperation. Two grades, stated separately rather than collapsed: **verified live** means holt was actually driven against the real host and observed to deny; **verified against host docs** means the schema is taken from the host's own current documentation but has not been fired against a real instance of it. A documentation-derived adapter is real work, not a guess — but it is not the same claim as having watched it deny.
- **MCP + advisory (deny hook planned)** — the host *supports* a deny hook, but holt ships MCP + AGENTS.md until its bespoke adapter is verified. A guessed hook format is worse than none.
- **MCP + advisory** — holt runs as an MCP server the agent may call, and its AGENTS.md is read as context.
- **advisory** — the agent only reads a rules file; holt is context, not control. The git floor still applies for any *local* agent.

Two rows in the table above land on **advisory** for a reason specific to that host, which a one-line grade can't carry (the generated table cell is deliberately just the grade — it has to match `strengthLabel()` and what `holt hosts` prints on the terminal, byte for byte, or the two would drift from each other the same way this file once drifted from the manifest):

- **Goose (Block)** — its only first-class MCP config is YAML (`~/.config/goose/config.yaml`, under `extensions:`), and that same file holds the user's own permissions and secrets. holt will not hand-merge a format it cannot parse safely, so it writes no MCP config here at all rather than guess. `src/integrate/hosts.mjs`'s `note` for `goose` has the exact block to add by hand (right field names: `cmd`, not `command`; `type: stdio`; `enabled: true` — a previous revision of that note got `cmd` wrong, which would have shipped a config Goose silently ignores).
- **Aider** — has no MCP client at all as of 2026-08-01 (confirmed against Aider's own current docs), and nothing is read automatically, not even AGENTS.md. Its coverage here is the universal git pre-commit hook plus a `CONVENTIONS.md` the user loads explicitly (`--read` or `.aider.conf.yml`'s `read:`).

Full per-host detail, including every `note` above, is available from `holt hosts --json`.

Whatever the host, the **git worktree lock** (agent-independent) and the **git pre-commit hook** remain the floor for any agent working on a real local checkout.
