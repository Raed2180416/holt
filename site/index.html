The transaction layer between coding agents and Git.

Available now

A complete local coordination surface for the agent-to-Git workflow.

Holt is useful today wherever agents share a local Git repository: inspect the whole workstream set, understand relationships, protect unique work, choose a landing order, and make cleanup recoverable.

01 / DECISION

Exact gates

status, risk, and gate show the path, operation, mode, and Git-object evidence behind each consequential decision.

02 / ACTION

Reversible cleanup

protect, rescue, clean, quarantines, and restore form a recovery-first loop. Clean is a dry run until explicitly applied.

03 / ACCESS

Agent surfaces

Reach the same repository intelligence through the CLI, TUI, project-scoped MCP with 16 decision-oriented tools, and supported host integrations. holt hosts keeps observed coverage visible.

04 / LOCAL-FIRST

Offline by default

Repository analysis, local refs, gates, and ordinary operation stay local. Setup actions and package downloads are disclosed separately in the audit trail.

05 / EVIDENCE

Open to re-running

Feature proofs, recovery scenarios, and benchmark contracts are available to run from source. Exercise Holt against the workflow that matters to you and inspect the evidence behind every decision.

06 / LICENSE

Free core

The single-repository core is available under FSL-1.1-MIT for any purpose other than a defined Competing Use. Internal commercial use is permitted within that boundary.

Coverage you can see and extend

Holt makes its operating map explicit, so teams can adopt the proven local core and extend the same evidence contract to the environments they run.

  • Local agents gain immediate worktree intelligence beside the repository they modify.
  • Project-scoped host adapters bring the same decision contract into supported agent environments.
  • Windows, large repositories, LFS, submodules, and sparse-checkout can be exercised through repeatable workflow evaluations.
  • Ignored, unique, and partially observed bytes remain protected until the repository proves they are represented elsewhere.

Try the local core

Map your repository in minutes.

Install from the official GitHub release, point Holt at a repository, and begin with read-only status. The same surface can then protect valuable work, coordinate landing order, and move verified cleanup into recoverable quarantine.

quick start / local repository
$ npm install -g https://github.com/Raed2180416/holt/releases/latest/download/holt.tgz
$ cd your-repo
$ holt status
$ holt protect
$ holt clean --apply # fresh-check, then locked quarantine
