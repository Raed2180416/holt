For anyone running AI coding agents

Never lose work your agents wrote.

Your AI assistants work in several copies of your project at once. holt keeps track of what each one made, and stops anything — human or AI — from deleting work that exists nowhere else.

The problem

Work disappears, and nobody notices.

When an assistant finishes, it leaves its work in a side copy of your project. Those pile up. Eventually someone clears them out — and the names, dates and file counts tell them nothing about what is actually inside.

In our tests, an AI assistant asked to tidy up deleted 13 of 16 copies — including all five holding the only version of something. It kept two empty ones, because they were named IMPORTANT-do-not-delete.

With holt running, that never happened once. Not because the assistant behaved better — because git itself refused.

How it works

Three things, running quietly.

👀

It reads what's inside

Not names or dates — the actual content. It knows when two assistants built the same thing, and when one holds something no other copy has.

🔒

It locks what matters

Anything holding the only copy is locked automatically. git itself then refuses to delete it, whichever tool tries.

🧹

It clears the rest

Everything already saved elsewhere can go in one command — re-checked the moment before it is removed.

Setup

One command wires up every assistant you use.

Claude Code, Cursor, Codex, Copilot, Gemini, Zed, Windsurf, Cline, Amp, Factory, Warp and more — plus plain git, so you stay protected even when nothing else is running.

$ holt integrate ✓ AGENTS.md — the file every assistant reads ✓ MCP servers — tools your assistant can call directly ✓ Safety hooks — dangerous commands refused before they run ✓ git hook — the backstop, always on

After that you can forget about it. holt auto locks anything at risk and tells you what is safe to clear — it never deletes anything by itself.
